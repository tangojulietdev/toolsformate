# Tools for Mate

Maritime tools for the watchkeeper by Tango Juliet Dev: ROB, ETA, speed, ventilation, unit converter, hydrostatics interpolation and deadweight / max cargo intake.

Installable PWA that works offline. All data stays on the device.

`source/tools-for-mate-single-file.html` is the editable single-file version of the app.

`garbage.html` is the Garbage Stowage Board: GMP drum layout per deck with fill levels, remaining space and category totals (MARPOL Annex V A to K). Editable for any vessel, export/import setup as JSON.
