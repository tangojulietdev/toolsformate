# Meridian Tools for Mate

Maritime tools for the watchkeeper by Tango Juliet Dev: ROB, ETA, speed, ventilation, unit converter, hydrostatics interpolation, deadweight / max cargo intake, proofread, time zones, load line zones, a Calculator (salinity and DWA, days, SF and density, trim and draft, rolling period and turning heel, ballast exchange, anchor holding, mooring hours (Form 5 time sheet), NRE days for Indian seafarers) and a Garbage Stowage Board (GMP drums per deck, fill and free space, MARPOL Annex V categories, editable per vessel) and a Budget tab (contracts and salary by pay day, ledger, recurring EMIs and SIPs, monthly budgets, and the final in hand forecast for any date).

Installable PWA that works offline. All data stays on the device.

`source/tools-for-mate-single-file.html` is the editable single-file version of the app.

UI: macOS style window with sidebar and unified toolbar on desktop, iOS list to detail navigation on phones. Control metrics adapted from [Puppertino](https://github.com/codedgar/Puppertino) (MIT).
