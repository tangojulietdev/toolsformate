# Meridian Tools for Mate

Maritime tools for the watchkeeper by Tango Juliet Dev: ROB, ETA, speed, ventilation, unit converter, hydrostatics interpolation, deadweight / max cargo intake, proofread, time zones, load line zones and a Garbage Stowage Board (GMP drums per deck, fill and free space, MARPOL Annex V categories, editable per vessel).

Installable PWA that works offline. All data stays on the device.

`source/tools-for-mate-single-file.html` is the editable single-file version of the app.
